## 新成员阅读顺序

1. **开发规范**：先知道东西该怎么命名、代码放哪里；
2. **接口说明**：了解现有能力与返回结构；
3. **本地试跑说明**：把环境跑起来，执行 `scripts\试跑接口.ps1` 看数据；
4. **企划书**：理解业务背景与范围边界（哪些不做）；
5. `readme.md`：看当前进度和踩过的坑。

## 维护约定

- 改接口必须同步 `接口说明.md`，并在同一次提交里完成；
- 新增问题写入项目根目录 `readme.md`，按编号追加，不记录口令与密钥；
- 新增权限点必须同时更新 `sql/cangxiaozhu_menu.sql` 与 `接口说明.md`；
- 本文档只做索引，不重复具体内容。
